# UI
create in this react app with typescript
don't change the eslint configuration
use of 'any' type is not allowed
use default export where possible
use typescript type instead of interface
the context hook should be use
the context, provider and logic should be in 3 separated files in the context directory
all calculation should be in the utils directory\*

# controls
## gas
There should be 4 buttons to add or reduce the flow by 0.5 or 0.25 l/h

## water
There should be buttons to fill and drain the water amount
Filling and draining should be 0.5 % per second
